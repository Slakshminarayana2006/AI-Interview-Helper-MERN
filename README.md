# AI Interview Helper 🎯

An AI-powered interview preparation platform built on the MERN stack. Upload your resume and a job description, and get a personalized interview report — match score, tailored technical & behavioral questions, skill-gap analysis, and a day-by-day preparation plan — generated by Google's Gemini AI.

**🔗 Live Demo:** [ai-interview-helper-mern.vercel.app](https://ai-interview-helper-mern.vercel.app/)
**📦 Repository:** [github.com/Slakshminarayana2006/AI-Interview-Helper-MERN](https://github.com/Slakshminarayana2006/AI-Interview-Helper-MERN)

---

## ✨ Features

- **Resume + Job Description Analysis** — Upload a resume (PDF) along with a target job description and a short self-description.
- **AI Match Score** — Get a realistic 0–100 compatibility score between your profile and the role.
- **Tailored Interview Questions** — Auto-generated technical and behavioral questions, each with the interviewer's intention and a model answer.
- **Skill Gap Detection** — Identifies missing or weak skills with a severity rating (low / medium / high).
- **Day-Wise Preparation Plan** — A structured, multi-day study plan with daily focus areas and tasks.
- **AI-Tailored Resume Generation** — Generates an ATS-friendly, one-page HTML/PDF resume customized to the job description.
- **Report History** — All generated interview reports are saved per user and can be revisited anytime.
- **Authentication** — Secure JWT-based auth with HTTP-only cookies.

## 🛠️ Tech Stack

**Frontend**
- React 19 + Vite
- React Router 7
- Tailwind CSS 4
- Axios

**Backend**
- Node.js + Express 5
- MongoDB + Mongoose
- JSON Web Tokens (JWT) for authentication
- bcrypt for password hashing
- Multer for file uploads
- Cloudinary for file/image storage
- Puppeteer + pdf-parse for PDF parsing and generation
- Zod for schema validation

**AI**
- Google Gemini API (`@google/genai`) — powers question generation, match scoring, skill-gap analysis, and resume tailoring

**Deployment**
- Frontend & Backend hosted on Vercel

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- A MongoDB instance (local or [MongoDB Atlas](https://www.mongodb.com/atlas))
- A [Google Gemini API key](https://ai.google.dev/)
- A [Cloudinary](https://cloudinary.com/) account (for file storage)

### 1. Clone the repository

```bash
git clone https://github.com/Slakshminarayana2006/AI-Interview-Helper-MERN.git
cd AI-Interview-Helper-MERN
```

### 2. Backend setup

```bash
cd Backend
npm install
```

Create a `.env` file inside `Backend/`:

```env
PORT=4000
MONGODB_URL=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
GOOGLE_GEMINI_API_KEY=your_gemini_api_key
CLOUDINARY_CLOUD_NAME=your_cloudinary_cloud_name
CLOUDINARY_API_KEY=your_cloudinary_api_key
CLOUDINARY_API_SECRET=your_cloudinary_api_secret
NODE_ENV=development
```

Run the backend:

```bash
npm run dev
```

The server will start at `http://localhost:4000`.

### 3. Frontend setup

```bash
cd ../Frontend
npm install
npm run dev
```

The app will be available at `http://localhost:5173`.

## 🔌 API Overview

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/api/auth/register` | Register a new user |
| POST | `/api/auth/login` | Log in and receive a JWT cookie |
| POST | `/api/auth/logout` | Log out the current user |
| GET | `/api/auth/get-me` | Get the currently authenticated user |
| POST | `/api/interview/interview-data` | Upload resume + job description to generate an interview report |
| GET | `/api/interview/getAllReport` | Get all interview reports for the logged-in user |
| GET | `/api/interview/getReportsById/:reportId` | Get a specific interview report |
| GET | `/api/interview/getresume/:interviewId` | Download the AI-tailored resume as a PDF |

All `/api/interview` routes require authentication via JWT.

## 🧠 How It Works

1. The user signs up/logs in and uploads their resume (PDF) along with a job description and a short self-description.
2. The backend extracts text from the resume using `pdf-parse`.
3. The extracted resume, job description, and self-description are sent to the Gemini API with a structured (Zod-validated) prompt.
4. Gemini returns a structured JSON report containing the match score, questions, skill gaps, and preparation plan.
5. The report is stored in MongoDB and rendered on the frontend, where users can revisit past reports or generate a tailored resume PDF.
